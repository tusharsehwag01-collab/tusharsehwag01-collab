### Hubble image processing · Python astronomy

Experiments with real Hubble FITS data, including Cat's Eye Nebula processing variants and M51 filter/source notes. The published scripts explore stacking, background subtraction, cosmic-ray cleanup, colour mapping and contrast.

- [Hubble repository and setup notes](https://github.com/tusharsehwag01-collab/hubble-image-processing)
- [Cat's Eye H-alpha variant](https://github.com/tusharsehwag01-collab/hubble-image-processing/blob/main/build_catseye_final.py)
- [M51 research notes](https://github.com/tusharsehwag01-collab/hubble-image-processing/blob/main/M51-README.md)

The repository is a **learning project**, not a NASA-endorsed pipeline or a fully packaged scientific tool. Input FITS data and rendered output images are not included; setup and scientific limitations are documented.

### The Living Mystics · illustrated storytelling

[The Living Mystics on YouTube](https://www.youtube.com/@TheLivingMystics) is a separate creative project exploring Indian and Eastern contemplative texts through illustrated stories and inquiry.

Production work includes the two-part Buddha-life films, Kaṭha Upaniṣad adaptations, Heart Sutra Shorts and other story films. The workflow combines source notes, original scripts, scene manifests, artwork, narration, music, timed captions and verified video exports. Text, a teacher's interpretation and original artistic adaptation are kept distinct.

The channel is public; the production archives and renderer code are **not published in these repositories**. AI-assisted illustrations and synthetic voices are part of the production workflow, with project-specific disclosure and rights notes.
